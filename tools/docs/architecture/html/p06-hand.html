FlowsA hand

A table is always in one of four states. Everything else (whose turn it is, a sideshow waiting for its answer, the variation being chosen) is part of the hand inside BETTING.

{{svg:hand}}
  • The deal. Each funded seat pays the boot into the pot (in memory), and three cards are dealt from a deck shuffled with crypto/rand. A seat that cannot cover the boot is not dealt in. The first to act is the player on the dealer's left; turns go clockwise by seat index.
  • Blind and seen. Everyone starts blind. A blind bet costs the stake, a seen bet twice the stake. After four blind bets a player's cards turn over for them automatically.
  • The ladder. The server computes the legal amounts for the player on turn (betOptions): the chaal, then doublings up to the table's limits and the player's stack. The client shows exactly that list; any other amount is refused.
  • The turn clock. 25 seconds. A turn that runs out packs the player and counts a missed turn; three in a row removes them from the table.
  • How a hand ends. Everyone but one has packed; or two players are left and one pays for a show; or the table's round cap or pot cap forces a showdown; or a player fires a missile (three or more players still in), which shows every hand at once.
  • Sideshow. A seen player may ask the player who acted just before them to compare hands privately. The loser packs. Nothing is charged, and the asked player has 6 seconds to accept or decline. A Force Sideshow costs a hammer and cannot be declined.
{{code:go-server/internal/game/table.go|Table.act: the checks every move passes, then the dispatch (comments trimmed)}} func (t *Table) act(userID string, action Action, req ActRequest) (ActResult, error) { if t.hand == nil { return ActResult{}, NewGameError(CodeNoHand, MsgNoHand) } s := t.findSeat(userID) if s == nil { return ActResult{}, NewGameError(CodeNotSeated, MsgNotSeated) } if s.status != SeatActive { return ActResult{}, NewGameError(CodeNotInHand, MsgNotInHand) } if action != ActionSee && t.variationPending() { return ActResult{}, NewGameError(CodeVariationPending, MsgVariationPending) } if action != ActionSee && t.hand.turnSeat != s.seatIndex { return ActResult{}, NewGameError(CodeNotYourTurn, MsgNotYourTurn) } if action != ActionSee && t.hand.sideshow != nil { return ActResult{}, NewGameError(CodeSideshowPending, MsgSideshowPending) } var result ActResult var err error switch action { case ActionSee: result, err = t.see(s, false) case ActionChaal: result, err = t.bet(s, BetChaal, req.Amount, req.ActionID) case ActionRaise: result, err = t.bet(s, BetRaise, req.Amount, req.ActionID) case ActionPack: result = t.pack(s, PackReasonPack, true) case ActionShow: result, err = t.show(s, req.ActionID) case ActionSideshow: result, err = t.requestSideshow(s) case ActionForceSideshow: result, err = t.forceSideshow(s, req.ActionID) case ActionMissile: result, err = t.fireMissile(s, req.ActionID) default: return ActResult{}, Errorf(CodeUnknownAction, MsgUnknownActionFormat, string(action)) } if err != nil { return ActResult{}, err } if action != ActionSee { s.missedTurns = 0 // a real move clears the idle count } return result, nil } {{/code}}

Who wins an exact tie

Hands are ranked by one function, Evaluate: high card, pair, color, sequence, pure sequence, trail. Suits never break a tie, so two hands can be exactly equal. The pot is never split; the rule depends on how the comparison was started.

ComparisonAn exact tie goes
Showagainst the player who called the show
Sideshow, Force Sideshowagainst the player who asked
Missileto the player who fired it, when their hand ties for the best
Round cap, pot cap, or a tie among the other playersto the tied seat nearest the dealer going clockwise, the dealer's own seat first

What each player is sent

After every change the table emits state, and the socket layer sends each viewer their own copy, built by serializeFor(viewer) in view.go. There is no room-wide snapshot.

  • you.cards only once the viewer has seen their cards; every other seat carries only cardCount.
  • On blind and variation tables, and in poker rooms, other players' chips are null, never 0.
  • you.options (the ladder and which keys are live) exists only for the player on turn.
  • Each seat's picture (avatarUrl) and card back are public, in every viewer's copy. The card back, cardBackground {id, url, assetFormat, crop?, expiresAt?}, is the one that player chose, and the app draws it on that seat's face-down cards. A seat without one carries no key and its cards wear the app's bundled default back, as every card in a poker room does. A rented back runs out at expiresAt: the app draws the default from that moment, and one table timer, set for the earliest expiry among the seats, takes every back that has run out off its seat and sends the new state to everyone.
  • Cards are revealed to everyone only at a showdown, and a sideshow's cards go to its two players alone.

Variation tables and poker rooms

A variation table deals as usual, then the first player to act has 10 seconds to choose the hand's variation (Muflis, AK47, Joker, Hukam, Lowest Joker, Highest Joker, or 5-Card); if the clock runs out the server chooses Muflis. There is still one ranking: each variation is a wild-card rule and a comparison direction laid over Evaluate (variation.go).

The poker family (3-Card Poker, 5-Card Draw, Texas Hold'em, Omaha) lives in internal/poker. A poker room implements the same game.Room interface, runs on the same actor shell, and banks money at the same three checkpoints; it has its own events (poker:*) and its own five-card evaluator.
