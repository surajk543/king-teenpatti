    Socket.IO metrics

b.  Create custom metrics for WebSocket/Socket.IO connections:--
    Track:

    Current connected sockets
    Total connections
    Total disconnections
    Connections per second
    Disconnections per second
    Reconnects
    Socket errors
    Socket messages

    Create metrics such as:

    game_connected_sockets
    game_connections_total
    game_disconnections_total
    game_reconnects_total
    game_socket_errors_total
    game_socket_messages_total

    Use labels carefully.

    For example:

    game_socket_messages_total{event="makeMove"}
    game_socket_messages_total{event="joinGame"}

    Do NOT use high-cardinality labels such as:

    socket_id
    user_id
    game_id
    IP address

    because this can cause excessive Prometheus memory usage.
