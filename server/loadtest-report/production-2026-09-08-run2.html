How latency grew with the crowd

Every bot times each move from the moment it sends game:action to the server's acknowledgement — the same round trip a player feels between tapping Chaal and the chips landing in the pot. The dashed line is the stop rule.

Is the laptop or the server being measured?

A load generator that runs out of breath inflates every latency it reports. This run timed how late its own 100 ms heartbeat fired at each stage; if that number climbs with the crowd, the figures above it are the generator's, not the server's.

1,000 players: last run against this one

The first run held each stage for 40 seconds. This one held 1,000 players for minutes before going higher, so the 1,000-player row is the one to compare.

Every stage in numbers

Each stage adds players in batches of 25, waits for them to sit, then measures for the hold window. Latencies are milliseconds; throughput is measured over the window only.
